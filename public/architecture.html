SERVERLESS ARCHITECTURE

A small, private signal pipeline.

The browser handles quick advisory checks locally. Shared reports go through a managed API and stay private until review.

Why no S3 or Step Functions yet? This version only handles short text and URLs, so it has no file-storage need. Analysis is a single fast request, so workflow orchestration would add complexity without improving the MVP. Reports stay private; only curated sample indicators appear publicly.
